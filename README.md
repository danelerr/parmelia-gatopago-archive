# Parmelia Links — Historical Repository

This is the repository where Parmelia, Parmelia V2, and GatoPago were originally built.

All projects and active development have migrated to [GatoPago on GitHub](https://github.com/gatopago).
Visit the organization for the current repositories and more information.

This repository is no longer maintained and is kept only as a historical archive.
Earlier versions remain available in the Git history.
